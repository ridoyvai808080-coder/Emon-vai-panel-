# EMON Vai App — GitHub Pages

## ফাইল
- `index.html` — Download Gate page
- `emon-vai-app.apk` — APK

## GitHub-এ প্রকাশ করার ধাপ
1. GitHub-এ নতুন একটি **Public repository** তৈরি করুন, যেমন `emon-vai-app`.
2. এই দুইটি ফাইল repository-তে upload করুন:
   - `index.html`
   - `emon-vai-app.apk`
3. Repository → **Settings** → **Pages** এ যান।
4. **Build and deployment**-এ `Deploy from a branch` নির্বাচন করুন।
5. Branch হিসেবে `main` এবং folder হিসেবে `/ (root)` নির্বাচন করে **Save** করুন।
6. কিছুক্ষণ পর GitHub একটি `https://YOUR-USERNAME.github.io/emon-vai-app/` ধরনের site link দেবে।

## গুরুত্বপূর্ণ
এই page password ও follow-step browser-এর JavaScript দিয়ে চালায়। GitHub Pages-এর public source-এ password দেখা সম্ভব, তাই এটাকে শক্ত security/password protection হিসেবে ব্যবহার করবেন না।

Facebook/TikTok-এর আসল Follow status সরাসরি যাচাই করা হয়নি; visitor Follow button চাপার পর Download unlock হয়।
